# V2.1.0 — World Clock

Adds a 12-city World Clock entry below the existing Flip Clock, a searchable/filterable directory at `/time`, and independent pages for 32 cities such as `/time/los-angeles`. City pages show current device-based time, the local date, IANA time zone, current UTC offset, relative time and related city links. The selected Graphite design, settings and existing timing tools are retained.

City favourites use the existing IndexedDB settings transaction and survive reload when Remember preferences is enabled. Turning it off preserves choices in the open session but resets them on the next visit. No favourites are preselected as user choices; up to six supported unique cities are accepted. These local-only favourites are excluded from optional account sync and ordinary study backups. Merely displaying world clocks creates no study record or leaderboard credit and does not modify the active timer. Privacy/local-storage notices now describe the actual behaviour.

Time calculations use browser time-zone rules, including differing daylight-saving change dates and half/quarter-hour offsets. Initial server-rendered clock values are stable placeholders so the HTML does not misrepresent server time as the user's local time or cause timezone-dependent hydration mismatches. There is no external time API, location permission or new login requirement. Day/night icons are hour-band indicators, not sunrise/sunset calculations.

All 55 routes are prerendered with unique metadata and normal canonical routing; 48 public tool URLs enter the Sitemap. Unknown city URLs retain a real HTTP 404, and valid city trailing slashes redirect consistently. The public-only PWA shell contains 61 resources and continues excluding account/community/API responses. The existing consent-gated analytics bridge includes the new public routes while rejecting private fields and unapproved paths; no new analytics provider or consent default is added.

Validation before deployment: 95 tests passed, including real IndexedDB persistence, preference reset, active-timer isolation, sync exclusion, DST transitions, cross-day boundaries and safe analytics. Local release HTTP checks passed for routes, metadata, Sitemap and licences. Browser checks confirmed real time loading, city search/navigation, favourite persistence after reload, forget-preferences reset, mobile layout and no console errors.

Deployment identifiers and public checks are recorded after rollout. No D1 migration, OAuth credential change or production community mutation is part of this release. Earlier real Google login/profile/moderator-queue acceptance remains valid; actual room timer/chat/moderation actions are still a separate pending acceptance, and main promotion remains subject to that existing gate.
