# V2.1.1 — compact Flip Clock layout

The local Flip Clock now sizes its cards and digits together using both viewport axes. The clock has a bounded maximum width and taller card proportions; the heading, date and World Clock entry remain grouped, with the complete tool dock visible in the first viewport. The compact landscape arrangement puts date and World Clock entry side by side. Two-group clocks and Focus Mode use the same sizing rules. Existing colours, themes, city pages, timers, storage and backend behaviour are retained.

The layout is scoped to the local-clock-screen class on the Flip Clock route, so it does not restyle other timer tools or the city-clock component. Only that class, its stylesheet import and the new stylesheet change application behaviour; package version is 2.1.1.

Validation: production build, 95 existing regression tests, 61 local route/asset checks with robots/Sitemap/licences, and in-app browser checks at 1805x727, 1366x768, 844x390, 390x844 and 320x568. At every viewport, digit bounds fit inside their cards and the date, World Clock entry and complete dock fit inside the first screen. Additional checks confirmed mobile two-group clocks, Focus Mode and the anchor to all 12 popular cities. No local browser console errors were captured. No new unit tests were added for this CSS-only behaviour.
