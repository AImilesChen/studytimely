# V2.1.3 — move the external date down

Moves only the visible Flip Clock date down by 40 CSS pixels toward the user-marked position. Relative positioning preserves the clock, heading and dock geometry. The compact landscape layout retains its previous date position to avoid overlapping the dock. The date remains centred and live; portrait cards, both colons, themes and the removed Explore link stay as previously released. No model, storage, route, server, credential, binding or database changes.

Build, targeted HTTP checks and actual desktop/mobile browser measurements are recorded with the deployment after verification. No additional unit tests were added or full model regression repeated for this small CSS offset. The previous 95-test regression result belongs to V2.1.2.
