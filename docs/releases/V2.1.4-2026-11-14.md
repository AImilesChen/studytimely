# V2.1.4 — Beijing and Shanghai in the World Clock panel

Replaces Chicago and Toronto with Beijing and Shanghai in the shared twelve-city World Clock panel. Both use the existing Asia/Shanghai IANA zone and their existing independent city pages. The complete 32-city directory, saved favourites, layouts, clock settings and time calculations are unchanged. No migration or account changes.

Validation and production identifiers are recorded after release; this data-only edit uses focused existing time-zone tests and public/browser checks rather than rerunning the whole model suite.
