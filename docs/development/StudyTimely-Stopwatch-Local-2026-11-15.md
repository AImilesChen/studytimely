## Implemented behavior

- Dedicated StopwatchPage replaces the generic below-fold learning-goal/workspace panels. Lap is visible before starting and disabled until running; Pause/Resume retain the same run. View results scrolls to and focuses the report. An optional, page-local hundredths display does not add a saved/synced preference.
- One shared report supplies elapsed time, completed laps, fastest/slowest/average completed lap and a separately labelled unfinished segment. A captured lap cannot exceed an older screen-refresh timestamp. Results have newest/oldest sorting and 50-row paging. Ties share fastest labels; a single completed lap has no redundant fastest/slowest row tags.
- Copy results reads a fresh paused/completed local snapshot and prepares readable text, also opening a selectable summary. A blocked clipboard write leaves that manual fallback usable. CSV contains chronological completed laps and a separately labelled unfinished row, formatted times and numeric milliseconds. Export is disabled during a running/pending/unowned run and rejects changed timer identity, epoch or owner. CSV is a report, not an importable learning record or JSON backup.
- Reset with progress asks before clearing; Cancel preserves the run. The 24-hour New run action also asks before replacing results. Reset creates no learning history. All synthetic browser runs were reset after verification.
- Stopwatch background settling is separate from verified learning: long callback gaps do not invoke study-time review. Clock discrepancy pauses at checked elapsed time, including captured lap boundaries. A run stops at exactly 24 measured hours with no generic completion-bell event. Pause gaps do not consume that allowance.
- Ownership transfer keeps the running measurement continuous, preserves a paused run and disables the former controller. A legacy stopwatch review state can keep checked elapsed time/lap boundaries through Recover stopwatch without declaring learning minutes. Existing Study/Focus/Pomodoro accounting and Countdown behavior retain their separate safeguards.
- Active stopwatch state remains in this browser only. No new schema, dependency, API, authentication, binding, legal/analytics configuration or protected Sites adapter changes were made. Current runs remain excluded from JSON backups and account snapshots. Existing unfinished other modes cannot be started over from the Stopwatch page.

## Limits and next release

Actual device sleep, OS clock changes, certified timing accuracy, native fullscreen, forced storage failure, forced clipboard denial, offline network-disconnection recovery and authenticated cloud synchronization were not exercised in this browser run. Model tests cover simulated gaps/clock changes and repository persistence; these do not prove physical-device behavior. Do not describe browser timestamp resolution as certified millisecond accuracy. Search/analytics backend events were not reverified.

A later explicit publication request must rebuild release output, synchronize the exact source and verify the production deployment/artifact hashes and public browser flow. Existing independent community acceptance and main-promotion gates remain unchanged. No database migration is needed. Rolling back retains the previous supported timer format but removes the dedicated stopwatch interface and revised interruption behavior.
