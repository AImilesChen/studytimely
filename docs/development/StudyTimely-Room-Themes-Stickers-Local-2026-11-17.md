## Delivered behavior

- All ten fixed messages map to four matching static assets: open book, thumbs-up encouragement, existing gold trophy and coffee. Buttons show small previews; recent messages and full history show a larger sticker with the original text. Unknown/free-text messages remain plain text. History is static; newly arrived recent messages have one subtle animation, disabled by reduced-motion preference and suppressed during the receiver’s focus. No sound or per-message generation/review, no new learning credit.
- The room header and public directory show a compact theme label. Room theme & invitation replaces the inline overview editing form with a 560px native dialog: eight presets, optional 2–40-character custom theme, and a fixed pinned study notice. Owners can save, cancel and check reviewer availability. Errors preserve draft text; concurrent versions show an explicit reload-settings action. Inputs use 16px text, with 390px and 320px layouts verified.
- PATCH /api/community/rooms/:id/home accepts customTheme with subject, announcement and version. Omission preserves approved existing custom text for older clients; explicitly empty text restores the selected preset. Strict normalization, text length, control/markup rejection, local contact/safety filters, owner/member/mute/closure/CSRF checks precede review. Changed custom text uses the existing configured automatic reviewer and shared budget/cache/circuit; presets and unchanged approved custom text do not require a new call. Six changed-custom review attempts per room/hour and twenty overview saves per owner/hour are bounded.
- Final SQL rechecks exact live session, membership, mute, room closure, version and owner/current administrative permission after async review. Failures do not publish draft text. No fallback that approves arbitrary text using local rules alone.
- Approved theme enters owner account export; private themes stay outside the public directory. Privacy policy and the public guide now explain the theme, review, sticker and task/timer distinction.
