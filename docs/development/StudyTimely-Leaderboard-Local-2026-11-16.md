# Leaderboard — local implementation

Local preview: <http://127.0.0.1:4278/leaderboard>. This isolated localhost fixture has zero accounts and zero leaderboard rows. The signed-out state and empty board work without fake activity. QA at port 4276 uses a separate persisted local database with explicitly synthetic sample participants. Neither is production or real Google authentication.

## Delivered behavior

- A dedicated Leaderboard component replaces the old component embedded in Community. It uses the shared 1280px frame, responsive gutters, concise heading, account-state actions and links to study rooms and scoring instructions.
- Your progress distinguishes loading, signed-out, Google-link-required, profile-required, opted-out, participating and account-error states. Existing profile settings and first-profile setup use the current authenticated, version-checked profile API. Public ranking defaults off on first setup; the age/terms declaration stays unchecked and is required only for first creation. Cancel preserves saved choices.
- Today/This week/Current streak have keyboard-operated tabs, UTC dates, the next boundary and device-time equivalent, successful update timestamp and refresh. Search explicitly covers the displayed Top 100; 20-row pages retain actual ranks. Loading, no-score, no-match and request-failure states have separate messages/actions. Rows do not link to new public profiles or social features.
- Shared server SQL preserves the existing room-time/streak/opt-in/tie rules. The public response retains its prior fields and adds dates, server time and the full eligible participant count. New authenticated GET `/api/community/leaderboard/me` returns only the requesting Google-linked account's profile, exact period score/rank across the full population, and latest 30 daily snapshot rows. Caller-supplied profile IDs cannot select another person's data. All API responses retain private/no-store/noindex headers.
- Private daily results have distinct participation/loading/error/empty states and a collapsed result list. Settings explain inclusion of retained time and private-room contributions, public visibility/search engines, and removal of daily rank history on opt-out. The two existing Groups profile forms received matching disclosure text; their behavior is unchanged.
- The initial HTML contains a 2,644-word English guide and 12 answered FAQs covering participation, accounting, UTC periods/streaks, a worked example, troubleshooting, privacy, opting out, history and healthy use. Contents and related-tool links work. Desktop guide text is 18px, phone 16px.
- Revised title/description, visible breadcrumb and matching BreadcrumbList/WebPage markup. The public route is configured for indexing and Sitemap inclusion in release builds; local previews remain noindex with an empty Sitemap. Personal data is not prerendered; personalized/list containers also use data-nosnippet, which is not a guarantee that public nicknames cannot be indexed. No search ranking/rich-result/analytics collection outcome is claimed.
