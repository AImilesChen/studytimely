The existing /study-tracker now hosts Overview, Analysis, Reviews and Records, using the shared 1280px page edges, restrained Graphite colours, large summary figures and responsive single-column panels. The Study Center links to records and weekly reviews. The original free record history, raw CSV, full backup and long-term activity remain available. Public instructions now describe the real analytics/review workflow and preserve ten substantial FAQs. Canonical URL and base tracker SEO intent remain.

Example sessions/tasks/targets are synthetic, isolated, never written to real history, and cannot be exported, deleted, saved as reviews or turned into plans. Closing the example removes its query flag. Private view/example query URLs are noindex. Initial HTML contains instructions, not private or synthetic records.

Overview includes recorded time, active dates, known task completions, historical daily goal results, adaptive daily/grouped chart, subject allocation and rule-based observations. Previous periods use matching calendar weeks/months/years and local cutoff for unfinished periods; zero prior data has no invented percentage. Chart and hour-cell drill-down clips actual contributing intervals, preserving filters and a return action. Records retain detailed original intervals, whole-session deletion, free filtered CSV and independent all-subject 52-week calendar.

Analysis includes weekday/hour heat map, recorded-interval lengths, task estimate versus linked recorded time, daily target history and weekly target details. Global goals explicitly keep all-subject/all-mode scope; mode filters change recorded time, not the meaning of a task-completion event. Target details mark missing history and partial weeks. Tasks use the earliest known estimate at the period boundary/creation; older missing evidence is unknown. Timing patterns describe recorded activity, not proven attention, quality or mastery. Personal local records are the source; room ledger totals are not blindly added.

Reviews support week/month and current-period-so-far snapshots, subject/mode scope, comparable previous totals, private reflection fields, stale-source notices and explicit regeneration preserving reflections. Saving uses optimistic versions, with monotonic per-review timestamps to protect same-millisecond concurrent edits. Unsaved changes warn on view/period changes and leaving. Plan next step opens an editable date/estimate form; unfinished existing tasks retain their deadline, completed tasks create a follow-up, and no timer starts. Daily and weekly goal editing preserves dated evidence.

PDF, PNG summary and optional review JSON are prepared locally. PDF has a time chart and paginated report text; PNG has totals and subject names. Task details/reflections are excluded from PDF and review JSON unless selected. PNG never includes them. Full private workspace backup remains separate. PDF uses raster image pages; it is not a tagged/selectable-text PDF. Browser-generated download behaviour and visual output remain unverified in this session.

## Data, access and compatibility

New workspace.learning version1 holds append-only task/goal evidence, report zone and saved reviews. Baselines only establish observed state; they do not invent completion dates for legacy tasks or historical goals. Same-millisecond events retain causal order without changing their timestamps. Reviews preserve generated snapshots after source changes. Deleting a review clears its text/snapshot and retains a deletion marker, preventing stale imports from restoring it. Existing task/history/session ownership and privacy controls stay intact.

Validation, local IndexedDB repository, JSON backup/import and manual cloud merge include this data. Cloud writes from older clients that would strip existing history/reviews return UPDATE_REQUIRED and preserve the stored document. Existing 1MiB cloud-snapshot limit remains; automatic sync and larger cloud storage are outside this task. Bounds: 50000 planning events, 200 live reviews / 2000 total review markers, 80000 JSON characters per snapshot, 100 task rows per snapshot with total count disclosed. No D1 migration was added by analytics; prior unshipped0011/0012 belong to the separate group-access work.

GET /api/learning/features is no-store/noindex and returns only current access status. It uses the public build policy for free preview, plus live session + existing trusted account entitlement for subscriber access. No public granting or payment endpoint was introduced. Build configuration explicitly carries the preview policy into the Worker; preview enabled, expiry0 means available until the policy is changed, without automatic charging. Optional fixed expiry is supported and malformed expiry fails closed. Anonymous preview works without a database. Client refreshes access periodically, on account-status changes and visibility; known expiry closes advanced UI. No premium report data is processed server-side. Client UI gating of local computation is not DRM; future server-backed paid operations must enforce their own server permissions. Free records/CSV/backup and saved-review reading/data export survive expiry.
